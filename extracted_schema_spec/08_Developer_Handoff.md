# Developer Handoff

## Product

Brilliants Industrial Maintenance ERP

## Development Principle

Build a complete manual-first industrial maintenance ERP foundation. Do
not add IoT/AI complexity to V1.

## First Sprint

2.  Environment variables
3.  Supabase project connection
4.  Authentication
5.  Organization/plant setup
6.  Profiles
7.  Roles and permissions
8.  Base layout/navigation
9.  Audit foundation

## Definition of Done

A feature is complete only when: - DB migration exists -
RLS/authorization exists - API/service logic exists - UI exists -
validation exists - audit behavior is defined - loading/error/empty
states exist - tests pass - no hardcoded production data exists
