# Workflows and SOP

## PM Workflow

1.  Create equipment.
2.  Create PM template.
3.  Define frequency.
4.  Assign responsibility.
5.  Generate planned schedule.
6.  Technician opens task.
7.  Complete checklist.
8.  Record observations.
9.  Record parts/labour.
10. Submit completion.
11. Supervisor verifies.
12. Close and update history.

## Breakdown Workflow

1.  Breakdown reported.
2.  Maintenance reviews request.
3.  Work order created.
4.  Priority assigned.
5.  Technician assigned.
6.  Diagnosis recorded.
7.  Repair performed.
8.  Parts/labour recorded.
9.  Test performed.
10. Equipment restored.
11. Supervisor verifies.
12. Work order closed.

## Calibration Workflow

1.  Instrument registered.
2.  Calibration frequency configured.
3.  Due record generated.
4.  Calibration performed.
5.  Results entered.
6.  Pass/fail recorded.
7.  Certificate uploaded.
8.  Next due date calculated.
9.  Record approved/closed.

## Inspection Workflow

1.  Inspection template created.
2.  Inspection scheduled.
3.  Inspector executes checklist.
4.  Findings recorded.
5.  Corrective work created where required.
6.  Finding closed after verification.

## Shutdown Workflow

1.  Shutdown event created.
2.  Equipment/jobs selected.
3.  Jobs estimated.
4.  Resources planned.
5.  Jobs assigned.
6.  Execution tracked.
7.  Delays recorded.
8.  Jobs verified.
9.  Shutdown closed.
10. Post-shutdown report generated.

## Spare Issue Workflow

Request → Approval (if configured) → Issue → Work Order Consumption →
Stock Update.
