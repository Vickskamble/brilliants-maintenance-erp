# UI/UX Screen Specification

## 1. Navigation

Dashboard - Assets - Maintenance - Work Orders - Calibration -
Inspection - Inventory - Vendors - Shutdown - Costs - Reports -
Documents - Administration

## 2. Dashboard

Cards: - Total Equipment - Critical Equipment - PM Due - PM Overdue -
Open Work Orders - Breakdowns - Calibration Due - Current Month Downtime

Charts: - PM compliance - Breakdown trend - Downtime trend - Maintenance
cost - Top failure equipment

## 3. Equipment Screens

-   Equipment list
-   Add equipment
-   Equipment details
-   Equipment history
-   Components
-   PM plans
-   Breakdown history
-   Calibration
-   Inspections
-   Documents
-   Cost history

## 4. PM Screens

-   PM calendar
-   PM plans
-   Due PM
-   Overdue PM
-   PM execution
-   Checklist execution
-   PM history

## 5. Work Order Screens

-   Work order list
-   Create work order
-   Work order details
-   Assignment
-   Execution
-   Parts/labour
-   Verification
-   Closure

## 6. Mobile-Friendly Technician View

-   My work orders
-   Equipment search
-   QR scan
-   Checklist
-   Add reading
-   Add photo/document
-   Add spare
-   Complete task

## 7. Forms

Forms should use: - Clear labels - Required-field indicators - Inline
validation - Searchable dropdowns - Date/time pickers - Attachment
upload - Draft/save capability

## 8. UX Principle

A technician should be able to complete a routine maintenance record
with minimum navigation and minimum typing.
